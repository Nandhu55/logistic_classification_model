# Logistic Classification Prediction App

A Machine Learning web application built using **Streamlit** and **Logistic Regression** to predict loan approval status based on customer financial details.

## Live Demo

https://logisticclassificationmodel.streamlit.app/

---

# Project Overview

This project demonstrates a complete Machine Learning Classification workflow including:

- Data Collection
- Data Cleaning
- Feature Engineering
- Model Training
- Model Evaluation
- Model Deployment using Streamlit

The application predicts whether a loan will be:

- Approved
- Not Approved

based on user input features.

---

- Streamlit

# Machine Learning Algorithm

## Logistic Regression

Logistic Regression is a supervised machine learning algorithm used for binary classification problems.

In this project:
- `1` → Loan Approved
- `0` → Loan Not Approved

The model learns patterns from financial data and predicts approval probability.

---

# Dataset Information

The dataset contains:

- 1000 rows
- 8 columns

## Features

| Feature | Description |
|---|---|
| Age | Customer age |
| Income | Annual income |
| CreditScore | Credit score |
| LoanAmount | Requested loan amount |
| Experience | Work experience |
| Savings | Savings amount |
| TransactionCount | Number of transactions |
| Approved | Target variable |
